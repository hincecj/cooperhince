One HTML file per project "Read more" page.

To add one, copy `_template.html` to a new name with no spaces (e.g.
`my-project.html`), write your summary in it, then add
`page: "my-project.html"` to that project's entry in `../js/papers-data.js`.

See the root README, "Read more pages", for the full steps, how to write
LaTeX, how to add figures and how to add a simulation.
