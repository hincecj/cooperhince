Numerical Analysis: A Tourist's Guide Part 1

A derivation of a simple numerical differential equation solver, applied to simulate the famous three body problem and a damped pendulum in Python.

View PDF View GitHub Code

Summary

This write-up derives one particular method for solving differential equations numerically, then applies it to two real world examples. All of the mathematics was done by hand first, then transcribed and polished for readability. The main objective is a method for simulating the three body problem in Python, with some other applications and ideas along the way.

The method

For an explicit $n$th order ODE $y^{(n)} = f(x, y)$, the forward finite difference recursion for $y_k$ is

$$ y_k = h^n f(x_{k-n}, y_{k-n}) + \sum_{i=1}^{n} \binom{n}{i} (-1)^{i+1} y_{k-i} $$

with $x_k = x_{k-1} + h$ and $0 \lt h \ll 1$, where the starting values $y_0, y_1, \dots, y_{n-1}$ are determined from the initial conditions. The first chapter of the write-up derives this recursion using the shift operator $E$ and the forward difference operator $\Delta = E - 1$.

Applications

  • The $n$ body problem, with the three body case simulated in Python.
  • A damped pendulum.

Limitations

Truncation error and energy conservation are not covered. This is a basic implementation of some numerical ideas.
