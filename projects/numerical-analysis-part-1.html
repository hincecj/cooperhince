Numerical Analysis: A Tourist's Guide Part 1

Part 1 of the numerical analysis series covers a derivation of a simple numerical differential equation integrator, applied to simulate the famous three body problem and a damped pendulum in Python.

View PDF View GitHub

Abstract

This write-up derives one particular method for solving differential equations numerically, then applies it to two real world examples. All of the mathematics was done by hand first, then transcribed and polished for readability. The main objective is a method for simulating the three body problem in Python, with some other applications and ideas along the way.

The Method

For a differential equation of the form $y^{(n)} = f(x, y)$, the forward finite difference recursion for $y_k$ is given by:

$$ y_k = h^n f(x_{k-n}, y_{k-n}) + \sum_{i=1}^{n} \binom{n}{i} (-1)^{i+1} y_{k-i} $$

with $x_k = x_{k-1} + h$. The starting values $y_0, y_1, \dots, y_{n-1}$ are determined from the initial conditions.

The idea behind this model is that a recursive relationship can be found for $y$ using the definition of the derivative to write $y^{(n)}$ as an $n$th forward difference divided by $h^n$, then expanding that difference with the binomial theorem and rearranging for $y_k$, the newest term.

This recursion can then be implemented into code to solve any differential equation of that form, with first order accuracy $O(h)$.
