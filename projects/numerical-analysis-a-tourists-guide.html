Numerical Analysis: A Tourist's Guide

This write-up explores some surface level numerical analysis, and covers a derivation of a simple numerical differential equation integrator, applied to simulate the famous three body problem and a damped pendulum in Python.

View PDF View GitHub

Abstract

My first write-up, Numerical Analysis: A Tourist's Guide, is not intended to be a rigorous or exhaustive analysis, but rather just a brief overview of some numerical techniques. Even calling it "numerical analysis" is a bit of a stretch. However, differential equations are the language of the universe, so I thought it was worth learning how to solve the equations that mathematics alone can't handle.

The objective of this write-up was to teach myself how to solve differential equations numerically, and to better understand the mechanics behind more advanced solving techniques like RK4 and LSODA. It became apparent very quickly that the methods I have "developed" in this write-up are quite inefficient and inaccurate, but it was an invaluable learning experience regardless.

Writing this document laid the groundwork for me to set up my own Runge-Kutta library in Python, a more powerful integration method that helped Apollo 11 land on the moon. Anyways, here's the main method from the write-up.

The Forward Finite Difference Method

Let's say you encounter a differential equation of the following form:

$$ \frac{d^n y}{dx^n} = f(x, y) $$

Many differential equations of this form are unsolvable using analytic techniques. Instead, we can set up a recursive relationship that approximates the solution from previous values. This can be achieved by stepping $x$ a small amount $h$ to the right, then “guessing” how much $y$ should change during that step using the original equation.

Using the definition of the derivative and some algebra, a simple implementation of this method is the generalised recursive sequence seen below:

$$ y_k = h^n f(x_{k-n}, y_{k-n}) + \sum_{i=1}^{n} \binom{n}{i} (-1)^{i+1} y_{k-i} $$

with $x_k = x_{k-1} + h$. The starting values $y_0, y_1, \dots, y_{n-1}$ are determined from the initial conditions of the system.

The full derivation of this model can be found in the attached PDF, which was initially done by hand.

Implementing this model into code is very simple when compared to Runge-Kutta and other integration schemes. However, the trade-off is accuracy: it is only first-order, with error $O(h)$, so halving the step size only halves the error.
