Numerical Analysis: A Tourist's Guide

This write-up explores some surface level numerical analysis, and covers a derivation of a simple numerical differential equation integrator, applied to simulate the famous three body problem and a damped pendulum in Python.

View PDF View GitHub

Fast Abstract

Numerical Analysis: A Tourist's Guide is exactly what it says it is. It is not a rigorous, overly in-depth analysis of numeric techniques, but rather what a tourist might use to explore the topic at a surface level. Differential equations are the language of the universe, so I thought it was worth learning how to solve the equations that maths alone can't handle.

The objective of this write-up was to teach myself how to solve differential equations numerically, and to better understand the mechanics behind more advanced solving techniques like RK4 and LSODA. It became apparent very quickly that the methods I have "developed" in this "paper" are terribly inefficient and inaccurate, but it was an invaluable learning experience regardless.

Writing this document laid the groundwork for me to set up my own Runge Kutta library, a powerful integration method that helped Apollo 11 land on the moon.

The Method

For a differential equation of the form $y^{(n)} = f(x, y)$, the forward finite difference recursion for $y_k$ is given by:

$$ y_k = h^n f(x_{k-n}, y_{k-n}) + \sum_{i=1}^{n} \binom{n}{i} (-1)^{i+1} y_{k-i} $$

with $x_k = x_{k-1} + h$. The starting values $y_0, y_1, \dots, y_{n-1}$ are determined from the initial conditions.

The purpose of this particular model is to find numerical solutions to differential equations without needing an analytic solution. The method is explicit, meaning each new solution $y_k$ is computed directly from earlier values, which keeps the implementation simple. The trade-off is accuracy: it is only first order, with error $O(h)$, so a small step size $h$ is needed.
